# 神経衰弱・Slow Reveal（2026-09-10）

## 教師の使い方

教材編集 →「ゲームをはじめる」→「神経衰弱」または「Slow Reveal」。
設定を変えて「はじめる」。次回・生徒用にも使う設定は「この設定を教材に保存」で保存する。
生徒に使わせる場合は「生徒の共有画面でこのゲームを使えるようにする」をオンにして保存し、既存の共有リンク・QRを配る。
Slow Revealは既定で生徒向けオフ。神経衰弱は既存の公開設定を尊重する。

神経衰弱は8/12/16/20枚（4/6/8/10件の教材カード）。単語と画像・単語同士・同じ画像・関連画像を選べる。
関連画像は教材編集の各カードにある「神経衰弱用の関連画像」から登録する。
必要な画像・単語が不足するカードは除外し、選択枚数に足りないときは開始を止めて案内する。
1人・ペア協力または2〜4チーム。そろったら得点が増え同チーム続行、不一致は900ms後に伏せて次チーム。
制限時間なし・1〜10分。全ペア成立・時間切れで終了。得点は保存しない。

Slow Revealは上・下・左・右・中央から4〜12段階で画像を開く。
手動または1〜10秒の自動進行。一時停止・再開、答えを見る、次へ。
教師には「ぜんぶ見せる」。画像は縦横比を保ち、中央は円形に開く。
小学校モードでは両ゲームとも英単語を表示しない。音声はセットの音声設定とゲーム中のオン・オフを優先する。

## 検証

型チェック・lint・本番ビルド、既存機能を含む自動テスト。
模擬教材のブラウザで20枚の配置・カードめくり、教師設定保存、Slow Revealの画像と答え、匿名ゲーム選択と開始を確認。
関連画像の先読み・解放、判定中の連打拒否、チーム得点、時間切れ、自動進行の一時停止、小学校の文字非表示、開始直前の公開状態再確認をテスト。
設定保存は既存games_config JSONの対象ゲームだけ更新し、別ゲームの設定を保持する。DB・サーバー関数・新規ワークフローの変更なし。

## 実機で残る確認

- 学校iPadで実教材のQRから3ゲームを開始できるか。
- 登録音声、タッチ、縦横回転、20枚の操作速度。
- 関連画像登録からゲーム開始までの本番アカウントでの一連の操作。

PCの模擬教材検査をiPad実機確認済みとは扱わない。完全なオフライン起動は対象外。
