## レビューの「要確認」で現状と異なっていた点

- ②の「開始ボタンまで毎回スクロール」は現行版では底部固定の開始ボタンがあり、全面的には該当しなかった。その既存機能を不具合扱いせず、今回指定された上部の短縮開始と折りたたみへ変更した。
- ③はAPI層にすでに404の文言分岐があった。画面側に再読み込みが残っていたため、分類とボタンの出し分けを統一した。
- ⑤の「失敗は赤トーストのみ」は全画面には該当しない。一括登録・入出力・共有・ミニゲームにはすでに残るエラー表示があり、削除して作り直すのではなく共通形式へ揃えた。
- 神経衰弱の完成後の盤面保持・結果との往復・そろったカードの再生は9月15日の公開版ですでに実装済み。新機能として二重実装せず、既存動作を保ち写真とテストで確認した。

小学校モードの旧「正解時だけ英単語表示」は今回の強制非表示の条件と矛盾するため無効化した。DBの既存フィールドは削除していない。

## DB制約と画面操作の点検

`src/api/cards.ts`・`sets.ts`・`transfer.ts` の insert/update/upsert を列挙し、今回の変更で書き込み項目・必須項目・値の形式を増やしていないことを確認した。検索・最近つかった・画面モード・開閉状態・前回設定は端末内だけで扱い、DBへ追加送信しない。既存の教師用「教材に保存」とゲーム開始を分けている。

リポジトリの初期SQLには単語の1文字以上制約が残るが、現行AGENTS.mdには編集中の空欄保存を許す運用変更が記録されている。初期SQLを現在の実DBの状態とは断定しない。今回、SQLや実DBは変更しておらず、実DBの全制約の再照合は未実施。

## 短い動作確認手順

1. 教材一覧でセット名を入力し、「▶ あそぶ」→ゲーム→上部の開始ボタンで始める。使った教材が「最近つかった」に出れば成功。
2. フラッシュカード設定で「画面モード」を教室用にし、大きい単語と左右の薄い矢印、下部の操作ボタンを確認する。「やめる」は確認画面が出る。
3. 無効な共有URLでは「このQRコードは つかえません」と出て、再読み込みボタンがないことを確認する。
4. 神経衰弱は全てそろえても盤面が残り、音声を聞き直せる。「けっかを みる」から結果に進み、盤面へ戻れることを確認する。
