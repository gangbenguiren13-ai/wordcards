# 動作確認・テスト項目

自動テストは `npm test` で実行されます（GitHub にプッシュすると自動で走ります）。
以下は**iPad実機で人が確認する項目**です。フェーズごとに増えていきます。

## 自動テストの範囲（現時点）

- 文字列の正規化（大文字小文字・全角半角・拡張子・末尾連番の除去）
- バリデーション（対応形式・上限サイズ・単語空欄・重複・画像使い回し・カード上限）
- 画像の縮小寸法の計算（縦長・横長・正方形・拡大しない）

## P0・P1 の手動テスト

### 1. 認証

- [ ] 招待コードを空欄にすると登録できない
- [ ] 招待コードを間違えると「招待コードが正しくありません」と出る
- [ ] 正しい招待コードで登録でき、そのままログインされる
- [ ] 同じメールアドレスで再登録しようとすると「既に登録されています」と出る
- [ ] 「パスワードを忘れた場合」で再設定メールが届く
- [ ] ログアウトするとログイン画面に戻る

### 2. 教師用と生徒用の分離（重要）

- [ ] ログアウトした状態で `/t/home` を直接開くと、ログイン画面に飛ばされる
- [ ] ログアウトした状態で `/t/sets/（適当なID）/edit` を開いても、ログイン画面に飛ばされる
- [ ] 生徒用のURL（`/p/…`）のページに、管理画面へのリンクが**1つもない**
- [ ] 別の先生のアカウントでログインし、他人の教材セットが一覧に出ないことを確認する

### 3. 教材の登録

- [ ] 教材セットを作成できる（小学校／中学校を選べる）
- [ ] カードを追加し、単語を入力して画面を離れると保存される
- [ ] 写真を選ぶとサムネイルが表示される
- [ ] スマホで撮った大きい写真（3〜8MB）が、数百KBに縮んだと表示される
- [ ] **横向きで撮った写真が、横倒しにならず正しい向きで表示される**
- [ ] iPadで撮った HEIC 形式の写真が登録できる
- [ ] 10MBを超える画像は「上限を超えています」と拒否される
- [ ] GIFなど対応外の形式は「対応していない画像形式です」と拒否される
- [ ] mp3を登録すると「音声あり」になり、その場で再生できる
- [ ] 2MBを超える音声は拒否される

### 4. バリデーション表示

- [ ] 単語を空欄にすると、赤い「なおすまで保存できません」に出る
- [ ] 画像のないカードがあると、黄色い「確認してください」に出る
- [ ] 同じ単語を2枚作ると、重複の警告が出る（`Dog` と `dog` でも検出される）
- [ ] 同じ画像を2枚のカードに使うと、使い回しの警告が出る

### 5. 並べ替え・複製・ゴミ箱

- [ ] ↑↓ボタンでカードの順番を変えられ、再読み込みしても順番が保たれる
- [ ] 「A→Z」でアルファベット順に並ぶ
- [ ] 「シャッフルして固定」で順番が変わる
- [ ] 教材セットを複製すると、画像も含めてコピーされる
- [ ] **複製元のカードを削除しても、複製先の画像が消えない**
- [ ] 削除するとゴミ箱に入り、「もとに戻す」で戻る

### 6. iPad での操作

- [ ] Safari で表示が崩れない（横向き・縦向きの両方）
- [ ] ボタンが押しやすい大きさ（指で押して隣を誤爆しない）
- [ ] ダブルタップしても画面が拡大しない
- [ ] 機内モードにすると、上部に「ネットにつながっていません」と出る
