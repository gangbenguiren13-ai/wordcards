# 動作確認・テスト項目

自動テストは `npm test` で実行されます（GitHub にプッシュすると自動で走ります）。
以下は**iPad実機で人が確認する項目**です。フェーズごとに増えていきます。

## 自動テストの範囲（現時点）

- 文字列の正規化（大文字小文字・全角半角・拡張子・末尾連番の除去）
- バリデーション（対応形式・上限サイズ・単語空欄・重複・画像使い回し・カード上限）
- 画像の縮小寸法の計算（縦長・横長・正方形・拡大しない）

## P0・P1 の手動テスト

### 1. 認証

- [ ] 招待コードを空欄にすると登録できない
- [ ] 招待コードを間違えると「招待コードが正しくありません」と出る
- [ ] 正しい招待コードで登録でき、そのままログインされる
- [ ] 同じメールアドレスで再登録しようとすると「既に登録されています」と出る
- [ ] 「パスワードを忘れた場合」で再設定メールが届く
- [ ] ログアウトするとログイン画面に戻る

### 2. 教師用と生徒用の分離（重要）

- [ ] ログアウトした状態で `/t/home` を直接開くと、ログイン画面に飛ばされる
- [ ] ログアウトした状態で `/t/sets/（適当なID）/edit` を開いても、ログイン画面に飛ばされる
- [ ] 生徒用のURL（`/p/…`）のページに、管理画面へのリンクが**1つもない**
- [ ] 別の先生のアカウントでログインし、他人の教材セットが一覧に出ないことを確認する

### 3. 教材の登録

- [ ] 教材セットを作成できる（小学校／中学校を選べる）
- [ ] カードを追加し、単語を入力して画面を離れると保存される
- [ ] 写真を選ぶとサムネイルが表示される
- [ ] スマホで撮った大きい写真（3〜8MB）が、数百KBに縮んだと表示される
- [ ] **横向きで撮った写真が、横倒しにならず正しい向きで表示される**
- [ ] iPadで撮った HEIC 形式の写真が登録できる
- [ ] 10MBを超える画像は「上限を超えています」と拒否される
- [ ] GIFなど対応外の形式は「対応していない画像形式です」と拒否される
- [ ] mp3を登録すると「音声あり」になり、その場で再生できる
- [ ] 2MBを超える音声は拒否される

### 4. バリデーション表示

- [ ] 編集中の空欄は保存できるが、未入力エラーがある教材の共有・ゲーム開始は止められる（現行の運用）
- [ ] 画像のないカードがあると、黄色い「確認してください」に出る
- [ ] 同じ単語を2枚作ると、重複の警告が出る（`Dog` と `dog` でも検出される）
- [ ] 同じ画像を2枚のカードに使うと、使い回しの警告が出る

### 5. 並べ替え・複製・ゴミ箱

- [ ] ↑↓ボタンでカードの順番を変えられ、再読み込みしても順番が保たれる
- [ ] 「A→Z」でアルファベット順に並ぶ
- [ ] 「シャッフルして固定」で順番が変わる
- [ ] 教材セットを複製すると、画像も含めてコピーされる
- [ ] **複製元のカードを削除しても、複製先の画像が消えない**
- [ ] 削除するとゴミ箱に入り、「もとに戻す」で戻る

### 6. iPad での操作

- [ ] Safari で表示が崩れない（横向き・縦向きの両方）
- [ ] ボタンが押しやすい大きさ（指で押して隣を誤爆しない）
- [ ] ダブルタップしても画面が拡大しない
- [ ] 機内モードにすると、上部に「ネットにつながっていません」と出る

## UI/UXレビュー 2026-09-16：③ 生徒用エラー

- 自動: 無効URL・共有停止の404で再読込ボタンと教師リンクが出ない。
- 自動: NETWORKは再読込でき、復旧後に開始できる。開始直前の共有停止でもボタンを出さない。
- 実機: 有効なQRを機内モードで開くと通信案内と再読込ボタンが出る。接続を戻して再読込できる。


## UI/UXレビュー：② ゲーム設定

- 自動: 初回だけ展開。2回目の開始は折りたたみと要約を表示し、1タップで設定を開く。開閉選択をゲームごとに記憶する。
- 自動: 従来の先読み失敗時の再試行と小学校モード強制が通る。
- 実機: iPad縦向きで再訪し、スクロールせず最上部の開始ボタンを押せる。神経衰弱とスローリビールでも確認する。

## UI/UXレビュー：① 教材一覧

- 自動: 87セットから部分一致で絞り込み、日本語のかな・英語の大文字小文字を扱う。入力欄に連続入力してもフォーカスと値が保たれる。0件案内・検索解除あり。
- 自動: 「▶ あそぶ」→ゲーム選択→開始の3回の操作で先読みに進む。削除は「…」を開いて確認した場合だけ実行できる。
- 自動: 最近つかった3件は重複せず、削除済み・別教師の教材を表示しない。開始失敗は最近つかったに加えない。
- 実機: 87セットの中から目的のセットを10秒以内・3タップ以内でゲーム開始できる。一覧から削除を誤タップできない。通信速度・文字入力時間と実測結果を記録する（未計測を達成扱いしない）。

## UI/UXレビュー：⑤ 状態表示

- 自動: 保存成功はヘッダー右端「✓ 保存済み」が1.5秒で消える。エラーは自動消去せず操作直下で閉じる・再試行できる。
- 自動: MutationCacheの共通エラー経路を維持。教師ゲームの通知は3秒、生徒ルートではログイン有無にかかわらず非表示。神経衰弱の再生失敗も生徒画面には出さない。
- 自動: 読み込みは内容・枚数（未取得なら確認中）・進捗バー、3秒超で時間がかかっている案内を出す。
- 実機: 通信を切って単語・画像・音声・共有・複製・一括登録を操作し、エラーが消えず操作の近くに残る。復旧後に再試行できる。ゲーム中に通知が生徒画面に出ない。

## UI/UXレビュー：④ ゲーム画面

- 自動: 手元用8vh／教室用12vhを基準に表示。長い固有名詞は幅に合わせて縮小する。教室用の操作ボタンは下部に配置。
- 自動: 中央タップは表裏モードでも次へ。めくる操作は専用ボタン。左端の帯だけ前へ。連打制限を維持する。
- 自動: やめるの確認中は自動送り・キーボード送りを停止し、キャンセルで同じカードに戻る。旧「正解時のみ英単語」設定が残っても小学校では終了画面まで非表示。
- 実機: 教室後方6mから単語が読める。生徒の連続タップで「戻る」が誤発火しない。学校iPadの縦横回転後にも長い固有名詞が切れない。
