# WordCards デザイン方針

## ボタンのラベルと折り返し（2026-10-18追補）

- 短い操作名を縮んだ横幅へ押し込まない。共通ボタンは行内で縮ませず、横に置けない場合は親の次の行へ移す。文字サイズと最小タップ領域は維持する。
- 確認ダイアログの操作はラベルの自然幅を基準に配分し、足りなければ縦並びにする。「ゲームをつづける」「ゲームをやめる」は1行。低い画面ではダイアログ内部をスクロールできる。
- ゲーム上部・下部のボタンは画面幅に応じて左右の余白を調整する。520px以下の設定選択肢・人数選択は1列にし、狭い2列への押し込みを避ける。
- 長い開始ボタンは「前回と同じ設定で」「はじめる（枚数）」の区切りで折り返す。狭い画面の復習ボタンは左右余白を減らす。設定スイッチは必要なときだけON/OFF表示を次の行へ移す。説明文付きの選択肢や収まらない長い文言まで一律に改行禁止にはしない。
- ブラウザーで文字の行数・ボタン外への文字はみ出し・重なり・横スクロールを測り、iPad縦横と狭い画面の写真・操作結果を残す。学校iPad/Safari実機とOSの文字拡大は別途確認する。

## Liquid Glass（2026-10-18）

この節を現行の外観とする。下の各日付の仕様のうち、背景色・影・装飾の動き・狭い画面のマスコット寸法を更新する。

- 先生の管理・入口と生徒の3ゲームに、静かな青い背景、光の縁、半透明のパネル、柔らかい影を使う。主操作と状態の配色・ラベル・タップ領域は維持する。
- 単語・画像を読むカード面と入力欄は白。神経衰弱の裏は番号、一致後は金の枠と星・チェックで区別する。文字を読む面に背景の模様を透かさない。
- backdrop-filterは固定の大きなパネルとヘッダー・フッターだけ。めくるカードには使わず、ゲーム選択タイルの常時上下運動も止める。ゲームロジック・音声タイミングは変えない。
- ぼかし非対応時は不透明な面へフォールバックする。prefers-reduced-transparency / prefers-contrast: more と教室モードではぼかしを止める。prefers-reduced-motionによる動きの抑制も維持する。
- 管理画面用teacherGlass.cssはAppHeaderから遅延取得する。生徒入口に先生用フォント・CSSを追加しない。新しい画像、依存、外部フォントや通信先は追加しない。
- 520px以下のゲーム選択ではマスコットを140pxにし、吹き出しとゲーム名の幅を確保する。iPad幅での従来の大きなマスコットと64px以上のゲーム操作は維持する。
- ローカル画面サイズ検証と、学校iPad/Safariでの実機確認を別の記録にする。

### 色

| 役割 | 色 | 使いどころ |
|---|---|---|
| 主操作 | `brand-600` `#1d4ed8` | 画面に**1つだけ**。「はじめる」「つぎへ」「あそぶ」 |
| 副操作 | 白地＋`line`枠 | 戻る・設定・複製 |
| 危険 | `danger` 赤 | **常設ボタンにしない**。メニュー内か確認ダイアログ内のみ |
| 成功 | `ok` 緑 | 保存済み・正解 |
| 注意 | `warn` 黄 | 要復習★・警告パネル |
| 生徒用アクセント | `#f59e0b`（暖色） | 生徒画面の主操作。教師画面の青と**画面で見分けられる**ようにする |

色だけで意味を伝えない（記号＋文字を必ず併用）は現状どおり維持。

### 文字サイズ（最小値）

| 場面 | 最小 |
|---|---|
| 教師の管理画面 本文 | 16px |
| ボタンのラベル | 16px（主操作は18px） |
| 生徒画面のボタン | 20px |
| ゲーム中の単語（手元用） | 画面高の8% |
| ゲーム中の単語（教室用） | 画面高の12% |
| 進捗「3／10」 | 20px、教室用は28px |

### 余白・タップ領域

- タップ領域: 管理画面 44px、生徒画面とゲーム中 **64px**（現状の方針を維持）
- ゲーム画面の外周に **16px の安全余白**（iPadの画面端誤タップ対策）
- ボタン同士の間隔は最低 12px。主操作と危険操作は同じ行に置かない

### ボタン

- 形は角丸12px・2px枠で統一（現状）
- **ラベルは「動詞＋対象」**: 「はじめる」「つぎへ」「ゴミ箱に入れる」。「OK」「はい」は使わない
- アイコンは絵文字でよいが、**同じ意味に同じ絵文字**（音=🔊、復習=★、開始=▶）。一覧表を `docs/` に置く
- 生徒画面は**ひらがな主体**（現状どおり）。教師画面は漢字を使ってよいが、**同じ機能に同じ語**（例: 「復習」と「ふくしゅう」が混在しないよう、教師画面は「復習」に統一）

### 状態表示

| 状態 | 出し方 | 消え方 |
|---|---|---|
| 保存成功 | ヘッダー右端に「✓ 保存済み」 | 1.5秒で消える |
| 失敗 | 操作したボタンの直下に赤帯＋「もう一度」 | 消えない（閉じるまで） |
| 読み込み中 | 「よみこみちゅう 12／20」進捗バー。3秒超えたら「時間がかかっています」を追加 | 完了で消える |
| 空の状態 | イラスト＋1文＋次の行動ボタン（現状の一覧と同じ型を全画面に） | — |
| 警告（教材の不備） | 編集画面上部パネル（現状）。ゲーム開始画面でも同文言 | 直すまで残る |
| ゲーム中の通知 | **教師roleのみ**。生徒画面には出さない | 3秒 |

### モチベーション（要望への提案）

装飾ではなく「できたことが見える」設計にする。

- **終了画面の演出**: ★ゼロで達成したときだけ、紙吹雪（CSSのみ・1.5秒・軽量）。毎回出すと効かなくなる
- **その日の記録（端末内のみ）**: 「今日 3セット・42枚」を教材一覧の上に小さく。個人情報を保存しない範囲（サーバーには送らない）
- **クラスの記録**: 神経衰弱の「かかった時間」を、そのセットの端末内ベストとして表示。「前回より速い！」の一言
- **教師向け**: 教材一覧に「今週使った回数」の小さな表示（端末内カウント）。作った教材が使われている実感が続ける動機になる


## 実装範囲と補足

- 2026-09-16時点ではモチベーションの節は未採用。2026-09-29の本人指定で、紙ふぶきだけを下記の終了演出として採用する。日別利用数・ベストタイム保存は追加せず、得点・要復習はメモリ内のみを維持する。
- 単語の8vh／12vhは標準の最小値。長い語が幅を超える場合だけ、切れない大きさへ縮小する。
- 読み込み枚数が未取得なら「枚数を確認中」と明示し、架空の進捗は出さない。
- 教師画面では保存成功のみヘッダーへ。失敗は操作直下に残し、既存の共通エラートースト経路も維持する。生徒ルートでは教師通知を出さない。
- 「やめる」は確認ダイアログ。ゲームの通知3秒と、管理画面の消えない操作エラーを区別する。

## 生徒・ゲーム画面のテーマ（2026-09-29）

この節は生徒画面とゲームに適用し、上の旧アクセント色・ボタン形状・絵文字の指定を置き換える。2026-10-03に先生のログイン・ゲーム選択・設定・開始の読み込みにも適用する。教材一覧・編集・共有・入出力などの管理画面は従来のまま。

- 背景 `#2A2873`、パネル `#1F1D5E`、区切り `#3A3794`。色は各面へ明示し、子孫全体の文字色・背景色を上書きしない。テーマCSSは components 層に置く。
- 主操作は `#FFC53D`＋濃色文字、副操作は白、復習オンは `#FFD95A`、音ありは `#35D0A0`、音なしは `#DEDCF1`。危険操作は確認画面の赤 `#B91C3B`。状態を文字・SVG・aria-pressedでも示す。
- ボタンは角丸20px、影6px、押すと6px沈む。無効時も文字を薄くせず、彩度と操作不可カーソルで示す。タップ領域64pxを維持。
- 日本語は自前配信の丸ゴシック700一種類。英単語だけ WordCards Latin（元Andika Bold、内部書体名を変更）。教材名の未収録文字は端末フォントへフォールバック。外部フォント/CDNは使わない。
- 先生の入口は遅延読み込みの teacherStage.css と別書体名 WordCards Rounded Teacher（追加の漢字・記号のみ）を使う。生徒用 rounded-700.woff2 は変更せず、先生用CSS・フォントを生徒の入口で取得しない。元フォントに無い既存の ▸・▾・⚠・🔊 は端末の記号・絵文字へフォールバックする。
- 英語フォントは中学校のゲーム準備で読み始め、先読み・開始を待たせない。再生成は `npm run fonts:subset`、文字収録と容量検査は `npm run fonts:check`（ビルド前にも実施）。OFL本文と出典を public/fonts に同梱。
- アイコンの意味は上表を維持し、ゲームではSVGを使う。生徒の文言はひらがな主体、飾りにアルファベットを使わない。
- 神経衰弱は300ms、一致350ms・不一致900ms。フラッシュカードは即時更新と250msの連打防止を維持。表裏の切りかえだけ、新しい面が90度から0度へ回り込む260msの表示にする。05の修正Fに従い、つぎへ・まえへなどカードが変わる操作は160msで入ってくる動きにする。鏡像になる角度を通さず、教室モードとreduced-motionでは止める。ゲーム中の背景・マスコットは静止。
- reduced-motionでは装飾アニメーション・遷移を止める。終了の紙ふぶきは最大40個、1回、1.5秒以内。得点・復習はメモリ内のみ。学校iPadでの実機確認は別途記録する。

## マスコット3D（段階2・2026-10-01、ローカル実装）

- three / @types/three は試作と同じ 0.159.0 固定。モデルは基本形状だけで組み立て、必要な部品を名前でimportする。MIT本文は `public/mascot/THREE-LICENSE.txt`。外部モデル、CDN、計測サービス、効果音は追加しない。
- 取得開始はゲーム選択の初回描画後の空き時間だけ。読み込みと終了は取得済みモジュールを再利用し、カードの先読み中やゲーム中に3Dの取得を開始しない。ゲーム中・教室モードは静止画を維持する。
- 装飾全体をaria-hiddenにし、canvasだけtouch-action:none。タップで回転ジャンプ、横ドラッグで回転、離すと戻る。表示280〜330px、描画倍率は最大2。
- WebGL不可、reduced-motion、saveData、最初の30フレーム間隔の平均33ms超は静止画へ切り替える。画面外・非表示タブは描画を止め、復帰時は非表示時間を性能判定に含めない。表示後のreduced-motion/saveData変更とcontext lossも静止画へ戻す。
- 離脱時は描画予約・イベント・observerを解除し、renderer・形状・材質・テクスチャを破棄する。静止画はHTMLの保持用imgそのものを表示先へ移し、離脱後は元の場所へ戻す。no-storeとCPU低速時も開始後の再取得を避けるため、同じURLの新しいimgへ置き換えない。
- ゲームロジック・設定・音声の時点・待ち時間、DB、サーバー関数、ワークフローには変更を加えない。公開・学校iPad/Safariの確認はローカル検証と区別して記録する。
