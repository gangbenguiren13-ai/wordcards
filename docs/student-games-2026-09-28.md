# 生徒用ゲーム選択と協力人数（2026-09-28）

## 変更内容

- 共有リンクの最初の画面に、公開中のフラッシュカード・神経衰弱・Slow Revealを同列のボタンとして表示する。各設定画面からゲーム選択へ戻れる。
- 神経衰弱が協力設定（teams = 1）のとき、生徒が「ひとり／2人／3人／4人」を選べる。1台を囲む協力プレイであり、複数端末の同期や個人名の登録は行わない。
- 2枚をめくるたび、一致・不一致とも次の人へ交代する。全員のペア数を共有し、音声の聞き直しでは手番も得点も変えない。教師のチーム対抗設定は従来どおり。
- 人数・得点・手番はメモリ内のみ。人数は教材設定やlocalStorageに保存しない。
- 最新共有状態の再確認、先読みと失敗時の再試行、小学校の英単語非表示、完成後の盤面と結果画面、終了確認は維持。

DBスキーマ変更なし／サーバー関数変更なし／新規ワークフローなし。既存のNature・Sports・FruitのSlow Reveal公開フラグだけ、教師画面の通常の保存操作で有効にする。共有トークンは変更しない。

## 学校iPadでの確認手順

1. 同じQRを開き直し、ゲーム3種類が出ること。
2. 神経衰弱→「3にんで きょうりょく」→開始。2枚をめくると次の人へ進み、3番の次は1番へ戻ること。
3. そろったカードを押して音声を聞き直しても、手番やペア数が変わらないこと。
4. 全ペアがそろっても盤面が残り、結果と盤面を行き来できること。
5. 終了して別のゲームを選べること。小学校モードでは英単語が出ないこと。
