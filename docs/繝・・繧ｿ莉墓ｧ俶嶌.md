# WordCards データ仕様書 v1

作成日: 2026-08-27
対応文書: 開発計画書 v1（本書はその分冊。DBスキーマ・JSON・CSV・Storage・API・RLS・バリデーション定数を定義する）

---

## 1. 用語と識別子

- **セット (material_set)**: 教材のまとまり。教師1名が所有。
- **カード (card)**: 単語1つ＋画像（任意で関連画像・音声）。
- **共有トークン (share_token)**: 生徒アクセス用のランダム文字列。nanoid 21文字（既定アルファベット、約126bit）。
- ID はすべて UUID v4。タイムスタンプは `timestamptz`（UTC保存・表示はJST）。

## 2. DBスキーマ（Postgres / supabase migrations）

```sql
-- 教師のプロフィール（auth.usersに1:1。表示名のみ）
create table profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  display_name text not null default '',
  created_at timestamptz not null default now()
);

create table material_sets (
  id uuid primary key default gen_random_uuid(),
  owner_id uuid not null references auth.users(id),
  title text not null check (char_length(title) between 1 and 60),
  mode text not null check (mode in ('elementary','junior')),
  default_display text not null default 'image_only'
    check (default_display in
      ('word_image','word_only','image_only','front_image_back_word','front_word_back_image')),
  audio_enabled boolean not null default false,
  show_word_on_answer boolean not null default false,  -- 小学校: 正解時のみ単語表示
  games_config jsonb not null default '{}'::jsonb,      -- §3
  share_token text unique,                              -- null=未発行
  share_enabled boolean not null default false,
  school_shared boolean not null default false,         -- 第2段階布石(校内共有)
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  deleted_at timestamptz                                -- ソフトデリート
);
create index on material_sets (owner_id) where deleted_at is null;
create index on material_sets (share_token) where share_enabled = true;

create table cards (
  id uuid primary key default gen_random_uuid(),
  set_id uuid not null references material_sets(id) on delete cascade,
  word text not null check (char_length(word) between 1 and 50),
  image_path text,        -- Storageパス(§4)。nullなら画像未登録(警告状態)
  pair_image_path text,   -- 関連画像(小学校の神経衰弱「関連画像同士」用)
  audio_path text,        -- 音声。null可
  sort_order integer not null default 0,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create index on cards (set_id, sort_order);
```

`updated_at` はトリガで自動更新。単語の重複・同一画像の複数使用はDB制約にしない（仕様上「警告」であり保存は許すため。判定はフロントの validation.ts）。

## 3. games_config JSONスキーマ

セットごとのゲーム許可と既定設定。**キーが存在しないゲームは生徒に非表示**（教師画面では常に全ゲーム表示）。

```json
{
  "flashcards": {
    "enabledForStudents": true,
    "defaults": {
      "order": "sequential",          // sequential | random
      "advance": "manual",            // manual | auto
      "autoSeconds": 3,               // 1..10
      "display": null,                 // null=セットのdefault_displayを使う
      "showProgress": true,
      "audioAutoplay": false,
      "reviewMode": "mixed"           // mixed(混在) | rounds(まとめ)
    },
    "studentAdjustable": ["order", "advance"]
  },
  "memory": {
    "enabledForStudents": true,
    "defaults": {
      "cardCount": 12,                 // 8|12|16|20
      "pick": "random",               // sequential | random
      "pairType": "image_image",      // word_image|word_word|image_image|image_pairimage
      "timeLimitMinutes": null,        // null=なし | 1..10
      "teams": 1,                      // 1..4 (1=個人/ペア)
      "audioOnMatch": true
    },
    "studentAdjustable": ["cardCount"]
  },
  "slowreveal": {
    "enabledForStudents": false,
    "defaults": {
      "direction": "top",             // top|bottom|left|right|center
      "steps": 8,                      // 4..12
      "advance": "manual",            // manual | auto
      "autoSeconds": 3,
      "order": "random",
      "answerDisplay": "image"        // image|image_word|image_word_audio
    },
    "studentAdjustable": []
  },
  "whatsmissing": {},                  // 第2段階予約
  "hiddencard": {},                    // 第2段階予約
  "gesture": {}                        // 第2段階予約
}
```

小学校モード時の強制上書き（フロントで適用）: 生徒roleでは `display` は文字を含む値を無視して `image_only` 扱い、`answerDisplay` は `show_word_on_answer=false` なら `image` に固定。

## 4. Storage構成と書き出し形式

### 4-1. Storage

- バケット: `media`（**非公開**）
- パス: `{owner_id}/{set_id}/{card_id}/image.webp` ／ `…/pair.webp` ／ `…/audio.{mp3|m4a}`
- 保存されるのは圧縮後ファイルのみ（元ファイルは保存しない）
- セットの複製時は Storage の `copy` で新 set_id 配下へ物理コピー
- 物理削除は `purge-trash` 関数（日次）: `deleted_at` が30日超のセットの行とメディアを削除

### 4-2. 書き出し（エクスポート）形式: ZIP

```
{セット名}.wordcards.zip
├─ set.json
└─ media/
   ├─ {card_id}.image.webp
   ├─ {card_id}.pair.webp      (ある場合)
   └─ {card_id}.audio.mp3      (ある場合)
```

set.json:

```json
{
  "format": "wordcards-set",
  "formatVersion": 1,
  "exportedAt": "2026-08-27T09:00:00+09:00",
  "set": {
    "title": "どうぶつ",
    "mode": "elementary",
    "defaultDisplay": "image_only",
    "audioEnabled": true,
    "showWordOnAnswer": false,
    "gamesConfig": { "flashcards": { "enabledForStudents": true } },
    "cards": [
      {
        "word": "dog",
        "image": "media/3f2a…c1.image.webp",
        "pairImage": null,
        "audio": "media/3f2a…c1.audio.mp3",
        "sortOrder": 1
      },
      {
        "word": "cat",
        "image": "media/8b91…7e.image.webp",
        "pairImage": null,
        "audio": null,
        "sortOrder": 2
      }
    ]
  }
}
```

読み込み時は常に**新規セット**として作成（上書きインポートはしない）。`formatVersion` が未知なら拒否してメッセージ表示。将来の版上げは後方互換（読み込みは旧版を常にサポート）。

## 5. CSV／TSV列構成

1行目はヘッダ必須。列順不問・未知の列は無視。区切りはカンマ／タブを自動判定。文字コードはUTF-8(BOM可)／Shift_JISを自動判定。

| 列名 | 必須 | 内容 |
|------|------|------|
| word | ○ | 英単語（1〜50文字） |
| image_file | – | 対応させる画像ファイル名（後からドロップするファイルと§計画書10-1(4)の規則で照合） |
| audio_file | – | 対応させる音声ファイル名 |
| pair_image_file | – | 関連画像ファイル名 |
| sort_order | – | 整数。省略時は行順 |

サンプル:

```csv
word,image_file,audio_file
dog,dog.jpg,dog.mp3
cat,cat.jpg,cat.mp3
rabbit,rabbit.png,
```

行単位エラー（word欠落・50文字超・重複）は取込プレビューで行ごとに表示し、正常行のみ取込むか全体中止かを選ばせる。

## 6. RLSポリシー

```sql
alter table profiles enable row level security;
alter table material_sets enable row level security;
alter table cards enable row level security;

-- profiles: 本人のみ
create policy p_profiles on profiles
  for all using (id = auth.uid()) with check (id = auth.uid());

-- material_sets: 所有者のみ（anonは一切不可）
create policy p_sets on material_sets
  for all using (owner_id = auth.uid()) with check (owner_id = auth.uid());

-- cards: 親セットの所有者のみ
create policy p_cards on cards
  for all using (exists (select 1 from material_sets s
                         where s.id = cards.set_id and s.owner_id = auth.uid()))
  with check (exists (select 1 from material_sets s
                      where s.id = cards.set_id and s.owner_id = auth.uid()));
```

Storage（バケット media）ポリシー: `insert/update/delete` は `authenticated` かつパス第1セグメント = `auth.uid()` のときのみ許可。`select` ポリシーは付与しない（読み取りは署名付きURLのみ。署名発行は教師=クライアントSDK(自分のファイル)、生徒=`shared-set` 関数(service role)）。

生徒アクセスに anon ロールの直接クエリは使わない。`shared-set` が唯一の入口。

## 7. Edge Functions（API定義）

### 7-1. GET /functions/v1/shared-set?token={share_token}

認証不要。処理: トークン完全一致で `share_enabled=true` かつ `deleted_at is null` のセットを検索 → カード取得 → メディアの署名付きURL（有効期限7日）を一括発行 → 応答。レート制限: IPごと60req/分（超過は429）。列挙・部分一致・一覧APIは存在しない。

200応答:

```json
{
  "set": {
    "title": "どうぶつ",
    "mode": "elementary",
    "defaultDisplay": "image_only",
    "audioEnabled": true,
    "showWordOnAnswer": false,
    "gamesConfig": { "...": "studentAdjustable含む" }
  },
  "cards": [
    {
      "id": "…",
      "word": "dog",
      "imageUrl": "https://…signed…",
      "pairImageUrl": null,
      "audioUrl": "https://…signed…",
      "sortOrder": 1
    }
  ]
}
```

404: トークン不一致・共有オフ・削除済み（理由は区別せず同一応答）。**注**: 小学校モードでも `word` は応答に含める（正解時表示・教師プレビューに必要。表示制御はクライアント。単語はそもそも秘匿情報ではない）。

### 7-2. POST /functions/v1/signup

Body: `{ "email": "...", "password": "...", "inviteCode": "...", "displayName": "..." }`
処理: `inviteCode` を環境変数 `INVITE_CODE` と定数時間比較 → 一致時のみ service role で `auth.admin.createUser`（メール確認あり）→ profiles 作成。不一致は 403。レート制限: IPごと5req/時。

### 7-3. purge-trash（cron: 日次）

`deleted_at < now() - interval '30 days'` のセットについて、Storage配下メディア削除 → 行削除。

### 7-4. keepalive（GitHub Actions cron: 週2回）

`shared-set?token=healthcheck` を叩く（存在しないトークンで404が返れば関数・DBとも起動している）。

## 8. トークン・共有の状態遷移

```
未発行 (share_token=null, enabled=false)
  └─「共有する」→ 発行 (token=nanoid21, enabled=true)
       ├─「共有を止める」→ 停止 (enabled=false, tokenは保持) → 再開で同じURL復活
       └─「URLを作り直す」→ 新token発行 (旧URL即404)
```

## 9. バリデーション定数（validation.ts に一元定義）

| 定数 | 値 |
|------|----|
| 画像: 受理形式 | jpg / jpeg / png / webp / heic |
| 画像: 元ファイル上限 | 10MB |
| 画像: 保存形式 | WebP 長辺1200px 品質0.8（目標≤300KB） |
| 音声: 受理形式 | mp3 / m4a |
| 音声: 上限 | 2MB |
| 単語長 | 1〜50文字 |
| セット名 | 1〜60文字 |
| カード数/セット | 上限200（超過はエラー）、120超で性能警告 |
| セット数/教師 | 上限100（ソフト上限・警告のみ） |
| 神経衰弱枚数 | 8/12/16/20 |
| Slow Reveal段階 | 4〜12（既定8） |
| 自動送り秒数 | 1〜10 |
| 署名URL有効期限 | 7日 |
| ゴミ箱保持 | 30日 |
| share_token | nanoid 21文字 |

## 10. エラー分類（フロント共通）

- `NETWORK`（オフライン/タイムアウト15秒）→「つうしんエラー。もういちど」＋リトライ
- `NOT_FOUND`（共有404）→「このページは つかえません。先生に かくにんしてね」
- `FORBIDDEN`（RLS/認証切れ）→ 教師のみ発生: 再ログイン導線
- `VALIDATION` → 画面内インライン表示（§計画書10-4の区分）
- `RATE_LIMIT`(429) → 30秒待って自動リトライ（1回）

生徒向けエラーメッセージはすべてひらがな主体・2文以内で `messages.ts` に集約する。
